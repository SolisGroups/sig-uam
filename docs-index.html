Installation en 5 Étapes

Démarrer le serveur
deploy.bat serve (Windows)
./deploy.sh serve (Linux/Mac)
Accéder sur mobile
http://192.168.1.100:8080/sigweb-uam/
Installer l'app
Chrome: Menu (⋯) > "Installer l'app"
Tester la géolocalisation
Cliquez sur: 📍 Localiser
Exporter vos trajets
Suivi GPS > ⬇️ Exporter (format GeoJSON)

Fonctionnalités Géolocalisation

deploy.bat serve (Windows)

# Préparer déploiement

# Tester géolocalisation

Dépannage Rapide

L'app n'apparaît pas à l'installation?
Vérifiez manifest.json, videz cache Chrome, relancez
GPS ne marche pas?
Activez "Haute précision", attendez 30-60s, soyez dehors
Comment créer un APK?
PWABuilder.com ou voir INSTALLATION-ANDROID.md
L'app fonctionne offline?
Oui, service worker cache au 1er chargement
